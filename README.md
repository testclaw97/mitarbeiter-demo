# Mitarbeiter — concept demo (throwaway)

A single, self-contained web page that shows what the product *could feel like*,
to align with Eliseo. Everything inside is faked — no backend, no real AI.

- **It's just `index.html`** — open it in any browser, email it, host it anywhere.
- **Completely separate from the real project** (`~/ai-agents`). Delete this whole
  folder and nothing happens to the actual codebase.

## The flow it shows
1. **Meet the team** you can hire (4 AI roles) + simple pricing.
2. **Hire Lisa** — name her, pick a plan, pay (faked) → she "joins".
3. **Your office** — chat with Lisa, watch her stats, approve her draft emails.
